## 구분할 사항

- 실제 브라우저에서 CSV/XLSX 파일을 선택·업로드하는 동작, 모든 카드사 원본 양식, 홈택스의 모든 원본 양식은 직접 검증하지 않았습니다. CSV/XLSX 파서와 예시 컬럼/복수 파일·삭제/분류 서비스는 자동 검증했습니다. 지원 컬럼·단일 시트·파일 크기/행수 제한은 기존과 동일합니다.
- 일반 가입·이메일 인증·계정 잠금·탈퇴·문의 등록/답변·관리자 세부 변경은 서비스 자동 검증이며 실제 운영 서버 검증이 아닙니다.
- 모바일/모든 해상도·모든 모달·모든 관리자 탭의 수동 클릭 회귀를 완료한 것은 아닙니다. 기존 CSS와 반응형 규칙을 유지했습니다.
- 실제 Spring Boot/Oracle/Gemma3/메일 연결은 없으므로 해당 통합 테스트는 수행할 수 없습니다. 법정 세액 정확성을 검증한 것이 아닙니다.
- 서버 렌더 HTML 검사는 브라우저 이벤트 검증과 다릅니다. 이번 의도된 변경 때문에 이전 버전과 모든 화면 HTML이 일치한다고 주장하지 않습니다.
