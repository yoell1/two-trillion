## 원본과 실행 환경의 차이

- Google Fonts를 사용하는 원본 설정을 유지했으며 오프라인 폰트 파일로 재구성하지 않았습니다. 동일 글꼴 로딩에는 인터넷 연결이 필요합니다.
- localhost는 별도 출처이므로 운영 사이트의 브라우저 저장 데이터는 자동 이전되지 않습니다. 회원·관리자 체험과 기존 예시 데이터·저장 동작은 그대로 포함됩니다.

- 배포 자격증명·Git 이력·설치 라이브러리·빌드 산출물·런타임 캐시는 포함하지 않습니다. `.openai/hosting.json`은 원본 배포 메타데이터로 포함하며 로컬 실행에는 쓰이지 않습니다.
